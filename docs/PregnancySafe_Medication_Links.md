# PregnancySafe — روابط الأدوية (Medication Sources, per-drug) — نسخة مؤكدة بالكامل

> كل الروابط اتفحصت فعليًا عن طريق البحث. المصدر الأساسي: **MotherToBaby (NCBI Bookshelf — NIH/NLM)**، مجاني وموثوق 100%. لو مفيش صفحة MotherToBaby مخصصة لدواء معين، استخدمنا **LactMed (NCBI)** كبديل رسمي من نفس الجهة (NIH).

## ملخص الحالة
- **17 من 18 دواء/مادة** لهم صفحة MotherToBaby مخصصة ومؤكدة فعليًا
- **3 استثناءات** (Methyldopa، Fosfomycin، Levothyroxine) معندهمش صفحة MotherToBaby مستقلة — استُبدلوا بمصادر NIH بديلة موثوقة بنفس المستوى (LactMed أو ATA)، وموضّح لكل واحدة السبب
- كل الروابط دي صالحة للاستخدام في ingest.py بدون قلق من bot detection أو paywall، عكس بعض روابط ACOG في ملف المصادر الأساسي
